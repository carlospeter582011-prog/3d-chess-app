# 3D Chess (Flutter, native)

A native Android port of the 3D Chess web app. **No WebView**: the UI, chess rules, bot logic, camera and
animation are Dart; the 3D scene is drawn with Google Filament from Kotlin into a Flutter `Texture`.
All 3D models (your Staunton set, board, table) are bundled in the APK; no internet is used.

| Part | Where |
|---|---|
| Rules engine (castling, en passant, promotion, draws, undo, SAN) | `lib/chess/rules.dart` |
| Elo to Stockfish settings, UCI client | `lib/chess/elo.dart`, `lib/chess/uci_engine.dart` |
| Stockfish (on device, `stockfish` plugin) | `lib/platform/stockfish_transport.dart` |
| 3D board model, orbit camera, tweens, picking | `lib/scene/` |
| Filament renderer (Kotlin) | `android_overlay/kotlin/FilamentScene.kt` |
| Game flow, bot turns, save/resume | `lib/game/` |
| Menu, HUD, dialogs | `lib/ui/` |
| Tests | `test/` (`flutter test`) |
| 3D assets (converted from the original GLBs) | `assets/models/` |

## Build

```bash
sdkmanager --install 'platforms;android-37.2' 'build-tools;37.0.0'
tools/build.sh          # Analyze, test, and build the APK and AAB into dist/
```

The `android/` folder is generated by `flutter create` and customised by `android_overlay/`
(Gradle file with the Filament dependency, manifest, Kotlin sources, icons). Edit the overlay, not `android/`,
if you want changes to survive a regeneration; or edit `android/` directly if you keep it in the project.

Build with Flutter 3.50.0 and JDK 17. The Android app compiles against Android 17 SDK 37.2 and
targets API 37. The package declares a minimum of API 23. Flutter 3.50 officially supports API 24
and up, so verify Android 6 on an ARM64 device before relying on that minimum.

GitHub Actions (`.github/workflows/android-apk.yml`) runs the same script, checks the APK's SDK
levels and the native library alignment, and publishes the APK and AAB after a successful main-branch push.

## Models

`tools/prepare_assets.mjs` converts the original models: WebP textures to JPEG (Filament cannot decode WebP) and
generates the table and the flat board markers.
